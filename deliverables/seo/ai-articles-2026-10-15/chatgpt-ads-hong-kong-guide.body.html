一、ChatGPT 廣告是什麼：與 Google／Meta 廣告的分別

ChatGPT 廣告是 OpenAI 首個由官方直接營運的廣告版位，廣告以一張贊助卡形式，出現在 ChatGPT 回應文字的下方，並清楚標示為贊助內容，與模型的答案分開顯示。它與搜尋廣告最大的分別，在於配對邏輯：ChatGPT 廣告不靠關鍵字比對，而是判斷使用者當下對話的意圖與情境，再決定是否顯示相關廣告。

OpenAI 表明，廣告不會影響 ChatGPT 給出的答案，廣告系統與對話模型分開運作，廣告主無法塑造、排序或改動 ChatGPT 的回應，亦不會取得使用者的對話內容或個人資料。這一點對於講求品牌信任的香港企業尤其重要：投放 ChatGPT 廣告並不代表品牌可以直接控制 AI 的推薦結果。

廣告的顯示位置與格式

按 OpenAI 官方說明，一個 ChatGPT 廣告單位由六個部分組成，缺一不可。撰寫素材與規劃設計時，須逐一預備：

  • ▸廣告主名稱：在帳戶層級設定，顯示於每一個廣告之上
  • ▸網站圖示（Favicon）：即品牌標誌，在帳戶層級設定，須能在細小尺寸下辨識
  • ▸標題：使用者最先讀到的文字，須點明產品價值
  • ▸說明文字：補充標題，說明適用對象與使用時機
  • ▸落地頁連結：建議加入 UTM 追蹤參數，方便在其他分析工具中辨識來自 ChatGPT 的流量
  • ▸圖片素材：廣告單位內的視覺元素

哪一類人會看到廣告，這一點決定整個媒體規劃的數學。ChatGPT 廣告只向使用免費（Free）與 Go 方案的用戶顯示；Plus、Pro、Business、Enterprise 與 Edu 帳戶完全沒有廣告。同時，OpenAI 不會向被判定為未滿 18 歲的帳戶顯示廣告。換言之，如果你的目標客群幾乎必然是 Plus 或 Pro 訂閱者，你在 ChatGPT 廣告上可觸及的庫存，會比 ChatGPT 整體用戶基數小得多。

香港企業今日可行的三條路徑

既然香港註冊實體未能自助開戶，香港企業若想測試這個渠道，實務上只有三條路：

  • ▸經代理商與夥伴渠道：OpenAI 的代理商夥伴（包括 Dentsu、Havas Media、Omnicom Media、Publicis Groupe 與 WPP）與技術夥伴可協助企業購買 ChatGPT 廣告，不受自助開戶名單的地區限制
  • ▸以已開放地區註冊的實體投放：若企業在已開放國家（例如新加坡、台灣或英國）有註冊實體，可由該實體開戶並投放
  • ▸登記候補並等待開放：在 ads.openai.com 登記帳戶，待香港列入名單後收到通知

要注意的是，帳戶的國家、貨幣與時區必須與實際註冊地一致，不能為開戶而填寫非註冊地的國家。以不實資料開戶，可能無法通過審查，或影響日後的付款與帳戶狀態。

香港企業的實務建議

不要把「香港已開放」當成前提去規劃預算。先確認企業是否持有已開放地區的註冊實體；若沒有，與熟悉 OpenAI 夥伴渠道的團隊合作，是目前最直接的可行方式。

四、開戶流程與帳戶設定（Ads Manager Beta）

OpenAI 的 Ads Manager Beta 提供兩條開戶起點：一是在註冊過程中輸入網站網址，先建立第一個廣告與活動；二是略過廣告建立步驟，直接進入 Ads Manager 建立帳戶。兩條路徑最後都在 Ads Manager 內完成設定。

開戶五步

  1. 登入或建立帳戶：前往 ads.openai.com，以日常使用的 OpenAI 帳戶登入，或即時建立帳戶
  2. 選擇起點：輸入網站網址讓系統協助建立第一個廣告，或略過此步直接進入 Ads Manager
  3. 填寫廣告主資料：輸入廣告主名稱及其他必要資料，建立廣告主帳戶
  4. 設定付款方式：在 Billing 頁面輸入信用卡資料與帳單資料（例如公司名稱、帳單地址、發票電郵）；付款設定完成前，活動無法投遞
  5. 確認標誌與帳戶名稱，並邀請協作者：在 Settings 內確認標誌、帳戶名稱、品牌名稱與法定名稱；如需要，可邀請同事並指派 Admin、Member 或 Viewer 角色

廣告提交後須通過 OpenAI 的政策審查才會上線。OpenAI 的說明強調，審查、帳戶狀態、付款設定、活動狀態與預算排程，都會影響廣告能否開始投遞。

帳戶名稱、品牌名稱與法定名稱的分工

Ads Manager 使用三個名稱，各有用途，可以相同，也可以分別設定。開戶時輸入的單一廣告主名稱，會同時成為帳戶名稱、品牌名稱與法定名稱，日後可分別修改：

  • ▸帳戶名稱：在 Ads Manager 內辨識與管理帳戶之用
  • ▸品牌名稱：公開顯示於 ChatGPT 廣告旁的品牌名稱
  • ▸法定名稱：企業的註冊名稱，用於計費與商業驗證；修改時會觸發審查

🔴 開戶前務必確認三項設定

OpenAI 官方說明指出，帳戶的國家或地區、貨幣與時區，在帳戶建立之後無法更改。提交前必須逐一核對，因為這三項一旦設定錯誤，將無法在原帳戶上修正。

新自助帳戶初期只可投本國

部分新自助廣告帳戶，初期只可在帳戶所屬的「本國」投放廣告。即使你在活動中選擇其他國家，也無法覆蓋這項限制。只有當身份驗證獲得通過，並在本國累積達到所需的廣告消費之後，帳戶才會自動具備投放到其他支援國家的資格。僅建立活動或設定預算並不足夠。

這項規則對以境外實體開戶的香港企業尤其關鍵：新帳戶必須先在該實體所屬國家實際投放並消費，之後才有機會把廣告擴展至其他市場。

五、投放設定：目標、預算、受眾與定位限制

活動（Campaign）定義整體的廣告目標與預算，其下包含廣告群組（Ad group）與廣告。每個活動包含活動標題、目標、轉換事件（如選用轉換目標）、預算、開始與結束日期、目標國家、目標平台，以及可選的自訂受眾。目標一旦設定，就決定計價與投遞優化的方向。

三個活動目標

OpenAI 的 Ads Manager 提供三個目標，各對應不同的計費方式與優化方向：

目標計費方式適用場景
Views每千次曝光（CPM）品牌曝光、廣泛觸及
Clicks每次有效點擊（CPC）帶動網站流量、註冊
Conversions按有效點擊（oCPC）或按千次曝光（oCPM）優化至指定轉換事件（購買、註冊、提交查詢）

值得留意：選用轉換目標時，你仍然只按有效點擊或曝光付費，而不是按轉換付費。另外，活動目標與計費選項在活動建立後不能就地更改，需要以複製活動的方式處理。OpenAI 亦指出，CPC 活動建議以每次點擊美元 3 至 5 為起始上限，系統會提供競價強度提示，顯示競價是否可能限制投遞。

預算設定：每日預算與活動總預算

活動預算控制整個活動內所有廣告的支出，你可選擇「活動總預算」或「每日預算」。兩者的控制力度不同：

  • ▸活動總預算：設定整個活動期間的總支出上限，是控制總支出的較嚴方式
  • ▸每日預算：設定平均每日支出目標，屬於投遞目標，個別日子的實際支出可能高於或低於設定值；單日支出不會超過設定值的兩倍，七日內總支出不會超過設定值的七倍

預算週期以廣告帳戶所在時區的星期日至星期六計算。如果活動在一週內提早用盡額度，即使仍標示為啟用，也可能暫停投遞直至下一個預算週期。

情境提示不是關鍵字

ChatGPT 廣告沒有關鍵字比對。取而代之的是「情境提示」（Context hints），在廣告群組層級設定，用完整、具體的句子描述你的產品或服務適用於哪些對話、主題或情況。例如「為首次備戰五公里賽事的初學者而設的緩震日常跑鞋」，比單寫「跑鞋」更能提供有用的情境。

OpenAI 明確指出，情境提示不是精確比對的關鍵字，也不是定位規則，不保證廣告會在特定對話或受眾中投遞。配對會綜合考慮當前對話的意圖、落地頁、標題與說明，以及在用戶啟用廣告個人化時的更廣泛 ChatGPT 使用訊號。

自訂受眾與歐洲經濟區、瑞士的限制

活動可設定包含或排除自訂受眾。要留意兩項限制。第一，納入（inclusion）自訂受眾需要至少 25,000 名已配對用戶，排除（exclusion）則可用較小的受眾；受眾成員可以加入、移除或替換，而無須重建受眾或重新設定活動。第二，針對歐洲經濟區（EEA）或瑞士投放的活動，在當地廣告個人化尚未提供期間，應避免使用自訂受眾。

此外，活動可設定目標平台，包括 Android 應用、Android 網頁、桌面網頁、iOS 應用與 iOS 網頁；在 Insights 內亦可按平台細分成效。目標地區方面，新產品目錄活動只支援國家層級的地理定位，其他活動則可在支援的情況下定位至州、城市、市場與郵區。

素材最佳實務

OpenAI 就用戶體驗與成效，提供幾項素材指引。這些屬官方建議，並非成效保證，但在製作素材時值得參考：

  • ▸以效益為先：說明實際價值、適用對象與使用時機，而非只靠口號或通用行動呼籲
  • ▸為覆蓋而建：同一產品預備多組標題與說明變化，讓系統有更多機會找到相關配對
  • ▸素材彼此區分：每一組變化應帶出不同角度，而非重複同一訊息
  • ▸落地頁對應：連結至最相關的產品、系列或內容頁，而非一律連到首頁
  • ▸符合廣告政策：素材、圖片與落地頁須符合 OpenAI 的廣告政策，誤導或不相符的廣告可能被拒

六、量度、常見錯誤與風險

沒有一套可靠的量度，任何廣告渠道都難以優化。ChatGPT 廣告的量度工具包括 OpenAI Pixel、Conversions API 與第三方整合，並以相關性加權的第二價拍賣作為核心機制。

量度工具與報表

Ads Manager Beta 的報表目前包括曝光、點擊、支出、點擊率、平均每次點擊成本、平均千次曝光成本與轉換。曝光、點擊與點擊率的數據約每 15 分鐘更新一次；支出數據可能延遲 7 至 8 小時，因此顯示為零並不一定代表沒有產生費用。要量度轉換，須在 Ads Manager 設定轉換追蹤，可透過 Conversions API 或 JavaScript Pixel 完成；轉換優化活動亦要求帳戶已設定轉換追蹤，並使用受支援的標準轉換事件。

此外，你亦可在落地頁網址加入靜態追蹤參數（例如 UTM 參數），這些參數會隨廣告點擊保留，方便在現有分析工具中辨識來自 ChatGPT 的流量。將 ChatGPT 廣告的量度與 Google Analytics 等工具對照，有助建立一致的成效視角。

量度數據的更新節奏，同樣影響優化判斷。曝光、點擊與點擊率約每 15 分鐘更新一次，而支出數據可能延遲 7 至 8 小時。這意味著即時的支出顯示，並不適合用作判斷活動是否正在花錢的依據；檢視成效時，宜以較完整的時間窗口看待數據，避免因短暫的顯示延遲而誤判。

量度工具用途
OpenAI Pixel在網站上追蹤廣告互動後的轉換事件
Conversions API以伺服器端方式回傳轉換，提升量度完整度
UTM 參數在現有分析工具中辨識來自 ChatGPT 的流量
第三方整合與外部量度與技術夥伴對照成效

常見錯誤

投放 ChatGPT 廣告最容易出錯的地方，多半與帳戶設定和地區規則有關。以下幾項須特別留意。

素材與排程相關的失誤同樣常見。例如首次建立活動時，OpenAI 未必會顯示開始與結束日期的選項，這些設定要在活動建立後編輯，或建立下一個活動時才會出現。若只為查看這些設定而先行發布活動，廣告有可能在未設定排程之前就開始投遞。

新帳戶一開始就選擇多個國家系統只允許本國投放，其他國家不生效先在本國累積消費並完成身份驗證
把情境提示當作關鍵字堆砌配對無效，觸及與成效下降用完整具體的句子描述使用情境

風險與合規考量

除操作層面的錯誤，尚有幾項須從策略層面考慮的風險：

  • ▸受眾受限：廣告只向免費與 Go 方案用戶顯示，付費方案用戶（包括企業採購決策者）完全看不到，庫存與整體用戶基數不對等
  • ▸敏感主題不出廣告：個人健康、精神健康與政治等情境不會顯示廣告，部分受規管行業另有較嚴的資格要求
  • ▸渠道仍在演變：產品屬測試階段，功能、覆蓋與量度能力持續變動，規劃時須保留調整空間
  • ▸不可控制 AI 答案：廣告不影響 ChatGPT 的答案，品牌不能藉此直接影響 AI 的推薦內容

常見問題

香港企業今日可以自助開設 ChatGPT 廣告帳戶嗎？

不可以。按 OpenAI 官方 Ads Manager 可用性名單（共 63 個國家，本文整理日期為 2026 年 10 月），香港不在名單之內。自助開戶資格取決於投放與計費的法人實體註冊地。香港企業可改經 OpenAI 的代理商與夥伴渠道，或使用已開放地區註冊的實體投放。

哪些 ChatGPT 用戶會看到廣告？

廣告只向使用免費（Free）與 Go 方案的用戶顯示。Plus、Pro、Business、Enterprise 與 Edu 帳戶沒有任何廣告，OpenAI 亦不會向被判定為未滿 18 歲的帳戶顯示廣告。

ChatGPT 廣告的最低預算是多少？

最低每日預算按廣告帳戶的計費貨幣而定。按 OpenAI 官方資料，美元為 25、新加坡幣為 4.00、新台幣為 60.00、日圓為 2,500、歐元為 15、英鎊為 15。最低預算只是入場門檻，並非建議預算。

帳戶的國家、貨幣與時區可以之後更改嗎？

不可以。按 OpenAI 官方說明，帳戶的國家或地區、貨幣與時區在帳戶建立之後無法更改。提交前必須逐一核對，若設定錯誤，只能建立新的帳戶處理。

ChatGPT 廣告與 Google、Meta 廣告有何分別？

最大分別在於配對邏輯與可見用戶。ChatGPT 廣告不靠關鍵字，而是判斷對話的意圖與情境，並只向免費與 Go 方案用戶顯示；Google 與 Meta 廣告則以關鍵字或興趣與行為訊號配對，覆蓋所有用戶。ChatGPT 廣告亦缺乏人口統計與相似受眾定位，宜視為額外的探索與評估渠道。

新自助帳戶可以一開始就投放到多個國家嗎？

部分新自助帳戶初期只可在帳戶所屬的「本國」投放，選擇其他國家也不會繞過這項限制。只有當身份驗證獲得通過，並在本國累積達到所需的廣告消費之後，帳戶才會自動具備投放到其他支援國家的資格。

在歐洲經濟區或瑞士投放有何特別限制？

在廣告個人化尚未於當地提供期間，針對歐洲經濟區（EEA）或瑞士投放的活動應避免使用自訂受眾。此外，納入自訂受眾需要至少 25,000 名已配對用戶，排除則可用較小的受眾。

總結

ChatGPT 廣告是一個仍在快速演變、但值得香港企業提早理解的新渠道。它的核心事實是：廣告只向免費與 Go 方案用戶顯示，配對靠對話意圖而非關鍵字，而香港註冊實體今日仍未能自助開戶。與其相信「香港已開放」的傳言，不如先確認企業是否持有已開放地區的實體，並評估是否透過 OpenAI 的夥伴渠道投放。

如果你希望由可用性評估、開戶、素材與情境提示設計，到量度與優化一併處理，可參考我們的廣告投放服務、AI 代理商服務，以及人工智能應用服務，理解由渠道選擇到成效量度的完整流程。亦可延伸閱讀企業 AI 方案指南。
