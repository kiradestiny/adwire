## 1. 方案 A：後台編輯器即時內容檢查

### 為何需要

原有的 build 閘門只在 **build 時** 檢查，而且**只有 CI 抓得到後台資料**。結果是：在後台輸入禁字 → 本機 build 永遠測不到 → 要等 CI build 失敗才發現（2026-09-21 實際發生過一次，45 項失敗）。

方案 A 把檢查提前到「**打字那一刻**」。

### 交付物

| 檔案 | 作用 |
|---|---|
| `public/admin/assets/js/content-check.js` | 檢查器本體（自足、無外部依賴） |
| `public/admin/assets/css/adwire-admin.css` | 面板樣式（附加，不動原有規則） |
| `public/admin/blog-edit.php` | 已接線（7 個欄位） |
| `public/admin/portfolio-edit.php` | 已接線（15 個欄位，含 FAQ） |

### 行為

- **右下角固定面板**，可收起；顏色語意：🔴 必須修正 / 🟡 建議 / 🟢 通過
- **即時檢查**：輸入時 600ms debounce；TinyMCE 同步（`AddEditor` / `input change undo redo`）
- **提交前攔截**：
  - 有「必須修正」→ 阻止提交、列出問題、說明「這些內容會令網站 build 失敗」、需明確確認才可繼續
  - 只有「建議」→ 提示並可選擇繼續
- 每項顯示：詞語、建議寫法、出現次數、上下文、所屬欄位

### 三類檢查

**① 禁止字句（47 項）** — 與 build 閘門**同一份清單**，並移植了同一套**否定語境放行**邏輯（±60 字窗口、中文引號放行、只認多字否定詞）。

**② 簡體字** — 1,385 字集。**已排除繁體同樣通用的字**：涌（葵涌）、晒（做唔晒／唔該晒）、里（里程碑）、斗（漏斗）、划（划算）、强。

> ⚠️ 開發過程中發現原本錯誤地把「柜」列入豁免 —— 「柜」是簡體，正確繁體是「櫃」。已修正。

**③ 大陸用語（37 組）** — 只收「香港標準寫法一定不同」的詞：

服務器→伺服器、信息→資訊、反饋→回饋、轉化率→轉換率、落地頁→著陸頁、郵件→電郵、默認→預設、界面→介面、硬盤→硬碟、內存→記憶體、屏幕→螢幕、快遞→速遞、方便麵→即食麵、土豆→薯仔、西紅柿→番茄、公交→巴士、小票→收據、鼠標→滑鼠、光標→游標、字符→字元、點贊→讚好、短信→短訊、激活→啟動、優盤→USB 記憶棒、視頻會議→視像會議、算法→演算法、代碼→程式碼、編程→程式設計、程序員→程式員、緩存→快取、您好→你好 等。

**刻意不收**已經係香港標準的字（軟件、文案、人工智能、硬件、大數據、機器學習、聯網、高清、插件）—— 避免假警報令人不再相信這個工具。

### 測試

`node --check` 語法通過，另以 **40 個案例** 實測（A 應攔截 6 / B 應放行 10 / C 大陸用語 9 / D 香港標準字不誤報 8 / E 簡體字 7）：**全部通過**。

關鍵案例：「市面上無人能像我們一樣保證排名」**仍攔得到**（證明否定語境規則沒有造成假陰性）。

## 3. 🔴 開發過程中我造成並修正的兩個問題

### 3.1 誤改故意對照表

我的「質量→質素」批量替換，把兩個**故意列出大陸用詞**的對照表改壞：

| 位置 | 原本 | 被誤改為 |
|---|---|---|
| HK Market 頁 `terms` 陣列 | `質量 → 質素` | `質素 → 質素` |
| 小紅書文章 FAQ | 「質素」與「**質量**」的差異 | 「質素」與「**質素**」 |

**已修回**，並加了一次全站「同詞對同詞」掃描確認無同類問題。

> 教訓：批量文字替換必須先排除「引述／對照」語境。

### 3.2 令 `BlogContent.tsx` 變成空檔

我用 `open(p,'w').write(open(p,'r').read().replace(...))` —— Python 先以 `'w'` **截斷檔案**才讀取，結果寫入空字串，令 build 失敗（`File ... is not a module`）。

**已從 git 還原**，並發現原本標記的「郵件」其實是「垃圾郵件」「電子郵件」，**都是香港標準寫法、不需要改** —— 即係如果冇搞壞、就會誤改。

> 教訓：文字替換一律先讀入變數，確認後才寫入；不要在同一行做讀寫。

### 5.2 `app/about/AboutContent.tsx`（我的掃描工具有 bug）

`/about/` 仍顯示「轉化率」，但我的掃描報告「0 殘留」。

**根因：** 我的掃描腳本用 substring 判斷跳過目錄：

```
SKIP = {'.git','node_modules','.next','out','preview-build'}
if 'out' in root: 跳過
```

而 **`"out" in "app\\about"` 係 True**（"about" 含 "out"）→ **`app/about/` 一直被自己跳過**。

已改用**路徑元件比對**（`set(relpath.split(os.sep)) & SKIP`）重掃全站，確認其餘檔案乾淨。

### 5.3 `deliverables/` 內的字不改

重掃後 `deliverables/` 仍有「反饋／轉化率／信息流」及簡體字。這些是**歷史審計記錄**及 **GSC 原始數據匯出**（`seo-data/*.json` 含用戶實際輸入的簡體搜尋查詢）。不是網站內容，**不應改動**。
