# ADWire 短問卷／需求分流與預算預覽建議

狀態：研究及產品規格，未實作／未上線；未改 backend。2026-10-15。

## 推薦結論

做站內 React conditional wizard，暫名「找出適合你的方案與預算」，一般 5 題，技術自助分支 2 題結束；結果先公開，聯絡資料留到最後。不是全服務自動正式報價，不用 AI 編造報價。不用一個總分把高預算但不相關／只查技術的人送給 sales。

評估目標：sales 接受且有實際需求的查詢／流量；不是只看填表數。

## 問題與分支（客向用香港書面語）

### Q1 你這次主要想處理甚麼？
- 希望增加查詢／銷售
- 希望改善網站、系統或人手工序
- 已有項目，希望找團隊執行
- 只想查找技術教學或自行解決問題

選技術教學 → Q2 選主題（網站／廣告／SEO／AI自動化），直接顯示相關文章與服務說明，不要求電話，不生成 sales lead。保留「其實我需要付費團隊代辦」返回入口。

### Q2 目前最想改善哪個情況？（依 Q1 改題，單選主要問題）
增長分支：
- 有產品／服務，但查詢太少 → ads 候選（仍需看基礎）
- 已投放廣告，但查詢成本高／轉換差 → ads＋landing page 檢視
- 有網站，但搜尋曝光不足 → SEO／GEO 候選
- 有流量，但網站／社媒不足以建立信任 → 網站／內容候選

營運分支：
- 沒有網站／現有網站不合用 → web
- 回覆、預約或跟進花太多人手 → automation
- 資料分散／Excel及系統不能互通 → system／integration
- 內部文件搜尋／知識處理慢 → AI 知識庫評估，不預先斷定一定需要 AI

已知項目：選網站／系統／AI自動化／廣告／SEO／社媒內容／其他。跨境市場在結果或 scope 選擇處補問，並列人工確認，不硬套本地標準套餐。

### Q3 目前有甚麼基礎？（依 Q2 改題）
廣告：尚未開始／已有網站及可接單流程／正在投放單平台／正在投放多平台。
SEO：沒有網站／有網站但未做SEO／已有SEO想改善／多語言或大型電商。
網站系統：新建／改現有網站／需要登入、支付、預約或其他系統整合／範圍未定。
社媒：有素材可用／需要定期拍攝及製作／尚未有帳戶或品牌素材。
重要：多平台、網站整合或拍攝需求不自動全部包進標準最低價。資料不足顯示有條件的起價或需人工確認。

### Q4 這次可安排的投入大約是多少？
不能全服務用同一預算單位：
- 廣告：問「每月總投入（代操服務費＋付給平台的廣告費）」；先展示最低已公開組合，避免客人把 HK$5,000 當含代操。預算可選「低於所示起步投入／可達起步投入／較高預算／尚未確定但願意參考」。更高預算具體 bands 需對齊已確認方案。
- SEO／社媒：問每月服務費可接受範圍，清楚第三方成本另計。
- 網站／IT：問一次性項目總預算，以預算探索而非售價承諾；未核准的價格門檻不得自行當 sales 淘汰線。
- 「尚未確定」不等於零預算：先展示已確認門檻，問是否可接受；明確表示不考慮付費才導向自助。

### Q5 預計何時開始？
- 一個月內
- 一至三個月
- 三個月後
- 先了解，暫未有計劃

不預設「急＝一定接」；緊急項目仍需人工確認資源。聯絡階段可選填公司／網址及「你是否負責或參與採購」，毋須額外一整頁影響完成率。

## 結果分類：分別判斷 intent / fit / budget acceptance / readiness

A. 適合銷售：商業需求符合＋接受對應預算下限＋有委託意向。顯示一個主要推薦、原因、範圍、不包含、預算、下一步。
B. 需確認：預算未定但可接受參考投入／複雜IT／資料不足。顯示需釐清項目，允許有意向者提交摘要作人工預審；不要承諾立即排 sales call。
C. 未準備：明確無可投入預算／只有探索。給一至兩篇對應文章與準備清單；主CTA為自助，不推銷售預約。
D. 技術自助：直接文章及教學；允許轉付費代辦，避免錯失實際買家。

不能用「答題多＝分高」；不能因免費 gmail、行業大小、電話來源而判低質素。不暗中丟棄已提交查詢；前端只改入口與透明顯示，不宣稱做到防繞過的 server qualification。

## 報價資料：只用 repo 已公開方案，需建單一 config 再上線

已核對檔案：app/services/ads/AdsServiceContent.tsx、seo/SeoServiceContent.tsx、social/SocialServiceContent.tsx。
- Ads 單平台管理費 HK$3,800/月；雙平台 HK$8,800/月；企業管理費為廣告費15%，最低HK$8,800/月；媒體費另計，金額特大另議。
- SEO Starter HK$5,800/月、Growth HK$9,800/月、Premium HK$16,800/月；目前頁面寫單站單市場、3個月起、按月預繳；大型／多語言／大量SKU另議。
- 社媒目前基礎HK$8,000/月、進階HK$15,000/月；不可把拍攝等未包含項目視作包價。
- 複雜網站／CRM／AI：本規格沒有核准價目，不填虛構區間，不用第三方 agency 美金價格替代ADWire價。

Ads 的支出展示需列管理費＋廣告費＝總投入，而非只用管理費吸引。上線前測 15K、50K 案例和方案邊界；15K 和50K出現在相鄰方案範圍，不可以純粹 budget 一刀切選套餐，須同時看平台數和交付範圍。方案本身最終條款由負責人確認。

## 結果頁示例（非對個別客戶的正式報價）

推薦：先檢查廣告與接單頁面，而不是一次過購買所有服務。

## 實作選項

推薦：原生 Next.js / React 小型元件 + 可測純函式規則，動態載入互動部分，品牌及手機可控、無額外表單平台依賴；不需要外部 LLM，亦毋須新 backend 才能做分類和顯示結果。
替代：Typeform / Tally 等 hosted 工具適合快速驗證，但訂閱、cookie、第三方資料流向、CSP、頁速及樣式需評估；未查定價，不以「免費一定足夠」作承諾。
不推薦：自由聊天式AI報價，因收費可漂移、難重現，且客人可能輸入敏感業務資料。

第一階段在純 frontend 計算結果；有意向者自選將摘要填入現有查詢 message 或 WhatsApp 草稿（標示尚未發送，由客戶按送出）。目前 service 欄只可映射現有可接受值，不私自加 backend 白名單。CRM 自動路由／狀態／通知優先級不在今輪 frontend 範圍，若將來要做另行確認。

## UX、privacy 與驗收

- 每頁一個主問題，明示單選／多選，可返回、保留答案、變更上游答案清除不相容下游結果。
- 進度不能寫假題數；分支變長需更新。一開始不承諾未測的「30秒」，先寫約5題。
- 結果先顯示、非強制交電話換答案；銷售聯絡才要必要資料。
- 鍵盤可選、focus帶到題標、結果aria-live、錯誤明確，respect reduced-motion。
- 不把姓名、電話、電郵或完整答案送入 analytics URL/dataLayer。結果ID/分支可量測；sessionStorage如用僅存非敏感答案並可重設。
- analytics 事件建議：assessment_start / assessment_step_complete / assessment_result_view / qualification_cta_click / lead_submit_success；「CTA click」不是成功查詢。事件不能自動觸發現有廣告 lead conversion。
- 核心KPI：qualified lead／訪客、sales接受率、預算不符查詢比例、sales工時／成交；次要看答題完成率。未有baseline，不承諾提升百分比。
- 測試：每條分支、預算未知／無預算、切換上游、返回／刷新、價格邊界、超長摘要、手機320/390/430、無JS說明與服務／價格可讀、資料不外洩、無正式表單或CRM污染。

## 首頁放置

Hero 主CTA「找出適合你的方案與預算」，次CTA「查看相關案例」；已有清楚需求者仍有直接查詢入口，不強迫所有人答問卷。首頁出現具體的真實網站／系統／創意成果預覽，比再加泛化AI辦公室照片更能回答「你們實際做到甚麼」。只可用已核准公開資產，不冒充真團隊或真辦公室照片。
